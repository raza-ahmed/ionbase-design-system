# Live demo: Ionbase Ops

Storybook shows each component on its own. **[Ionbase Ops](https://raza-ahmed.github.io/ionbase-design-system/demo/)**
shows them working together, in a fictional AI ops console built only from
`ionbase-ui` and `ionbase-icons`.

- **Overview**: KPI tiles, charts coloured only by tokens, a date range
- **Agents**: a data table with filters, bulk actions and a typed delete confirmation
- **New agent**: a four-step wizard with per-step validation and a resumable draft
- **Runs**: an agent that shows its steps, stops for approval, and can be stopped at any point
- **Assistant**: streamed answers with inline citations and a stated confidence
- **Settings**: immediate toggles and save-together defaults, kept apart

A bar at the bottom of the demo switches light and dark, simulates latency, and
forces each screen into its loading, empty, error or partial-failure state.

Source: [`apps/demo`](https://github.com/raza-ahmed/ionbase-design-system/tree/main/apps/demo).
