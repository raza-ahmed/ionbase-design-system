# IonBase

Accessible React components, their stylesheets, and the design tokens they are
built on, in one package: **`ionbase-ui` {pkg.version}**, with{' '}
{Object.keys(index.components).length} components and{' '}
{Object.keys(patterns.patterns).length} patterns.

IonBase is built for enterprise software, and for the way it is now written:
often by a coding agent, with no one reading the docs first. So every
component ships a contract saying when to use it and what goes wrong, every
screen-level composition is written down with its loading, empty and error
states, and a lint plugin turns the rules into errors.

## Install

```bash
npm i ionbase-ui
```

React 18 or 19 is a peer dependency. Import the stylesheet once, at your app's
entry:

```tsx
import 'ionbase-ui/styles';
import { Button } from 'ionbase-ui';

export function App() {
  return <Button variant="primary-brand">Save</Button>;
}
```

Dark mode is `data-theme="dark"` on any ancestor, the whole page or one panel.
Icons are any SVG component; [`ionbase-icons`](https://www.npmjs.com/package/ionbase-icons)
is the optional set drawn for it.

## For coding agents

- **`ionbase-ui/llms.txt`**: the index, every component and pattern in one line each.
- **`ionbase-ui/meta/index`**: every component with its variants, in 12KB. Read it, then the one contract you need.
- **`ionbase-ui/meta/<Name>.json`**: one component's contract: when to use it, what to use instead, its accessibility, its anti-patterns.
- **`ionbase-ui/patterns/<Name>.json`**: a screen-level composition and its three states.
- **`ionbase-ui/eslint-plugin`**: the same rules as lint errors, for an app's ESLint config.

The same pages are hosted at
[`/llms.txt`](https://raza-ahmed.github.io/ionbase-design-system/llms.txt).
