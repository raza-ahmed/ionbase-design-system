# @ionbase-ui/react

Accessible React components for IonBase. Styles live in `@ionbase-ui/styles`; import them once at the app entry.

```bash
pnpm add @ionbase-ui/react @ionbase-ui/styles
```

```tsx
import '@ionbase-ui/styles/css';
import { Button } from '@ionbase-ui/react';

<Button variant="primary-brand">Save</Button>;
```

See [`docs/publishing.md`](../../docs/publishing.md) for install and the local publish flow.
